# Настройка аккордеона в конструкторе — прототип

Интерактивный прототип окна конструктора Saby: показывает, как настраивается левый аккордеон
(навигация по приложению) — добавление страниц, подменю и их редактирование.
Нужен для презентации, поэтому публикуется по ссылке.

## Ссылки

- Демо: https://accordion-prototype-seven.vercel.app
- Репозиторий (приватный): https://github.com/MarieSmi/accordion-prototype
- Проект Vercel: `maria-smi/accordion-prototype`

## Публикация

- Пуш в `main` публикует демо автоматически, другие ветки дают превью-ссылки.
- На сайт не попадает то, что перечислено в `.vercelignore` (служебная папка `.claude/`, README).
- Вручную: `vercel deploy --prod`.
- Адрес `accordion-prototype.vercel.app` занят чужим проектом — используем `accordion-prototype-seven.vercel.app`.
- Сайт открыт всем, у кого есть ссылка, вместе со всеми файлами (шрифты, скриншоты).

## Договорённости

- Стек: обычные HTML + CSS + JavaScript, без сборки.
- Всё, что в контентной области (дашборд и правая колонка), — скриншоты из макета.
- Шапка конструктора и правая панель: пока только наведение. Что делает каждый клик, решается отдельно.
- Окно конструктора — фиксированная сцена 1600×900, вписывается в окно браузера с сохранением пропорций.

## Поведение аккордеона

- Клик по пункту аккордеона открывает его **подменю**, страница при этом не меняется.
- Клик по пункту **внутри подменю** переходит на страницу.
- Клик по надписи **«saby»** в шапке аккордеона — переход на «Главную». Птичка и «+» — отдельные зоны.
- Наведение на пункт подсвечивает его, через задержку появляются команды ✎ и ⋮.
- Раздел текущей страницы отмечен синей полоской слева.
- Подменю закрывается по ✕, клику вне его или Esc.
- Открытие подменю (по клику или по наведению) и вид аккордеона (раскрытый, узкий, панель)
  настраиваются в окне «Меню» из шапки конструктора. Сейчас: раскрытый аккордеон, открытие по клику
  (`settings` в `app.js`).

## Открытые вопросы

- Подменю для остальных разделов (кроме Контактов, Календаря, Бизнеса) — придут скриншотами.
  Пока такие пункты по клику сразу открывают страницу раздела.
- Цвета наведения, которых нет в макете (пункты подменю, правая панель, «+» в аккордеоне, ✓/✕),
  подобраны вручную — нужны точные значения.
- Что делает клик по птичке-логотипу в шапке аккордеона.
- Для всех страниц из подменю сейчас показывается один скелетон из макета «Контакты».

## Отступления от макета

- Надпись «saby» в Figma набрана Maison Neue Extended, которого нет, — вставлена маской,
  вырезанной из макета (`assets/img/logo-saby.png`).
- Текст на тёмном фоне аккордеона чуть тоньше (начертание 350), чтобы совпадать с макетом визуально.
- В иконке календаря — сегодняшнее число.

## Структура

```
index.html        разметка окна конструктора
styles.css        стили и токены цветов из Figma
app.js            данные аккордеона, подменю, навигация, настройки
assets/fonts/     Inter, Accordion-Font (иконки разделов), cbuc-icons, cbuc-icons24
assets/img/       скриншоты контента, аватар, логотип, кнопки
.claude/serve.js  локальный сервер для просмотра
```
